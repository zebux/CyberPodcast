Comment proposer une ressource

  1. Vérifiez les critères de sélection ci-dessous.
  2. Préparez le format attendu avec les champs obligatoires.
  3. Envoyez le tout à cyberpodcast@zebux.org en précisant le nom de la ressource dans l’objet.

Critères de sélection

  • Le sujet principal est la cybersécurité, le cloud, le développement ou un sujet adjacent clairement utile à la communauté.
  • La ressource est publique, consultable sans accès privé et dispose d’un site officiel ou d’un flux RSS stable.
  • Le podcast est actif ou récemment actif ; un arrêt de publication peut être accepté si l’intérêt historique est explicitement justifié.
  • Il n’existe pas déjà de fiche pour la même ressource.
  • Le contenu n’est ni illégal, ni haineux, ni trompeur, et les liens d’écoute renvoient vers les plateformes officielles.

Format attendu

Voici le format attendu pour une proposition. Vous pouvez copier ce modèle directement dans votre e-mail :

  - id: mon-podcast
    name: 'Mon Podcast'
    category: ['Cybersécurité', 'Blue Team']
    language: fr
    host: 'Prénom Nom'
    status: active
    website: https://exemple.fr
    rss: https://exemple.fr/feed.xml
    apple_podcast: https://podcasts.apple.com/...
    description: 'Description courte et factuelle du podcast.'
    platform: Ausha

Champs obligatoires

  • id : identifiant unique en kebab-case, en minuscules et sans accent.
  • name : nom public exact de la ressource.
  • category : au moins une catégorie, par exemple Cybersécurité, Cloud ou Développement.
  • language : fr ou en.
  • website ou rss : au moins une source vérifiable ; le flux RSS est fortement recommandé.

Les champs host, status, spotify, youtube, description et platform sont facultatifs mais améliorent la fiche générée.

Envoyer la proposition

Copiez le modèle ci-dessus, ajoutez vos liens officiels et envoyez le tout à cyberpodcast@zebux.org. La ressource sera vérifiée avant ajout à l’annuaire.
