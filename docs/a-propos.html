Le projet

Un annuaire vivant des podcasts cyber

CyberPodcast référence 86 podcasts francophones et internationaux autour de la cybersécurité, du cloud et du développement.

Ce que fait le projet

Le site agrège des podcasts, vérifie leurs liens, récupère leurs derniers épisodes et enrichit les fiches depuis les flux RSS, Apple Podcasts et les sites officiels. Tout est généré statiquement : aucun serveur, aucun compte, aucun cookie.

Comment les données sont produites

  1. Les sources et les corrections manuelles vérifiées sont dans data/podcasts-*.yaml.
  2. Le pipeline Python fusionne, déduplique, enrichit et écrit podcasts.yaml.
  3. Un workflow GitHub Actions contrôle la santé des liens, régénère le site et publie GitHub Pages.

Rythmes de publication

Le rythme est calculé à partir de l’intervalle médian entre les dates de publication des épisodes récents, puis arrondi au nombre de jours entier le plus proche. Seuils utilisés : ≤ 2 j : Quotidien · 3–10 j : Hebdomadaire · 11–17 j : Toutes les 2 semaines · 18–45 j : Mensuel · 46–90 j : Tous les 2 mois · 91–120 j : Trimestriel · > 120 j : Irrégulier. Le nombre affiché entre parenthèses est cet intervalle médian, pas une périodicité contractuelle.

Automatisation

Le workflow tourne toutes les 30 minutes. Il récupère les nouveautés, met à jour les notes et les derniers épisodes, contrôle la santé des liens et redéploie le site. Les erreurs réseau ne bloquent pas la publication : les données précédentes servent de repli.

Contribuer

Une erreur, un podcast manquant, un flux cassé ? Ouvrez une issue ou proposez une correction dans data/podcasts-*.yaml. Les liens officiels et les flux vérifiés sont prioritaires.

Transparence

Les notes affichées proviennent d’Apple Podcasts et sont indicatives. Les liens d’écoute renvoient vers les plateformes officielles. Le code et les données sont publics sur GitHub.

Stack technique

Python, PyYAML, requests, feedparser, HTML/CSS/JavaScript vanilla, GitHub Actions et GitHub Pages. Aucun framework front, aucun tracker, aucune dépendance runtime. Le site a été vibecodé avec cette stack.
